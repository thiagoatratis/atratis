# Atratis Approval

Portal de aprovação de criativos e orçamentos de mídia paga da Atratis Digital, com geração de Pedidos de Inserção (P.I.).

Stack: React + TypeScript (Vite) e Supabase (Auth, Postgres com RLS, Storage, Edge Functions).

Em construção, por etapas. Instruções de configuração serão adicionadas na etapa 1.
